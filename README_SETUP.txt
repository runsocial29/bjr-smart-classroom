BJR Smart Classroom V4 ONLINE
================================

V4 เปลี่ยนระบบจาก Local Storage เป็นฐานข้อมูลออนไลน์ Supabase

ความสามารถ
- ครูสมัคร/เข้าสู่ระบบด้วยอีเมล + รหัสผ่าน
- เพิ่ม/แก้ไข/ลบห้องเรียนได้ไม่จำกัดระดับ
- รายชื่อนักเรียนแยกตามห้อง
- เช็กชื่อออนไลน์
- สุ่มนักเรียน
- หลายชิ้นงาน + คะแนนเต็มแต่ละชิ้น
- คะแนนและพฤติกรรมบันทึกออนไลน์
- นักเรียนแต่ละคนมีลิงก์และ QR เฉพาะบุคคล
- Student Portal แสดงเฉพาะคะแนนของเจ้าของ token
- ครูสามารถ "เปลี่ยนรหัส" เพื่อยกเลิกลิงก์เดิมได้

SETUP (ทำครั้งเดียว)
1) สร้าง Supabase project ที่ https://supabase.com/
2) เปิด SQL Editor แล้ววางไฟล์ supabase_schema.sql ทั้งหมด จากนั้น Run
3) ใน Supabase ไปที่ Project Settings / API (หรือ Connect/API keys ใน UI รุ่นปัจจุบัน)
   คัดลอก:
   - Project URL
   - Publishable key หรือ anon key
   ห้ามใช้ service_role key ในหน้าเว็บ
4) เปิด index.html
5) กรอก Project URL + Publishable/anon key
6) สมัครบัญชีครู แล้วเข้าสู่ระบบ
7) นำไฟล์ index.html, style.css, app.js ขึ้น GitHub Pages / Netlify / Cloudflare Pages
8) ที่เมนู "ลิงก์/QR" ใส่ URL เว็บไซต์จริง เช่น
   https://username.github.io/smartclassroom/
9) กด QR หรือคัดลอกลิงก์รายบุคคลให้นักเรียน

หมายเหตุด้านความปลอดภัย
- service_role key ห้ามใส่ใน browser เด็ดขาด
- ตารางทั้งหมดเปิด RLS และ anon ไม่มีสิทธิ์ SELECT ตารางโดยตรง
- Student Portal อ่านข้อมูลผ่าน RPC student_portal(token) ซึ่งคืนเฉพาะข้อมูลของ token นั้น
- ลิงก์นักเรียนเป็น bearer secret: ใครมีลิงก์ก็เปิดดูได้ จึงควรส่งเฉพาะเจ้าของข้อมูล
- ถ้าลิงก์รั่ว ครูกด "เปลี่ยนรหัส" เพื่อทำให้ลิงก์เก่าใช้ไม่ได้
